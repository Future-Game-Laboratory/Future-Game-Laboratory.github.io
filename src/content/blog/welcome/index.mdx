游戏很少从一个完整的答案开始。它更常从一个模糊的问题、一段手感不对的原型，或者一次没有按计划发生的测试开始。

未来游戏研究所建立这个 Blog，是为了保存这些容易在项目结束后消失的过程。我们会在这里记录设计决策、工程实验、研究笔记和开发复盘，也会诚实地写下没有奏效的方法。

## 我们会记录什么

- 游戏机制、叙事结构与玩家体验的观察
- 原型开发中的技术选择和工具实践
- 项目阶段性复盘，以及失败带来的具体结论
- 与游戏文化、创作方法相关的研究笔记

我们希望文章足够具体，可以被验证、复用或反驳；也希望它保留创作现场的不确定性，而不是事后把每条弯路都改写成直线。

## 从写作工具开始

这个站点本身也是实验的一部分。文章通过站内内容编辑器生成 MDX，并直接提交到 GitHub。每次提交都会触发 GitHub Actions，经过内容检查和静态构建后发布到 GitHub Pages。

接下来，我们会从真实项目中逐步补上内容。欢迎阅读，也欢迎沿着仓库里的提交记录观察这个实验室如何生长。
